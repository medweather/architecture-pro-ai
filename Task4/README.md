# Задание 4. RAG-бот с техниками промптинга

Рабочий RAG-бот над базой знаний Stellar Chronicles (Задание 2, индекс из Задания 3).

## Архитектура пайплайна

```
Запрос пользователя
      │
      ▼
Эмбеддинг (BAAI/bge-m3, 1024)          ← тот же энкодер, что при индексации
      │
      ▼
Поиск top-K в ChromaDB (cosine)         ← Task3/chroma_db
      │
      ▼
Сборка промпта: System (CoT) + Few-shot + Контекст + Вопрос
      │
      ▼
LLM: gpt-4o-mini (OpenAI-совместимый API)
      │
      ▼
Ответ с шагами (CoT) + источники
```

## Компоненты

| Компонент        | Реализация                                               |
|------------------|----------------------------------------------------------|
| Загрузка индекса | `Retriever` — ChromaDB persistent + bge-m3               |
| Приём запроса    | `RAGBot.answer()` / REPL                                 |
| Поиск            | ChromaDB `query()`, top-3 по cosine                      |
| Промптинг        | `build_messages()` — System + few-shot + контекст        |
| Генерация        | `_call_llm()` — gpt-4o-mini через `/v1/chat/completions` |
| Интерфейс        | REPL (`rag_bot.py`)                                      |

## Техники промптинга

### Few-shot

В промпт добавлены **2 примера** «вопрос → эталонный ответ» из той же предметной области. Примеры собраны из реальных
документов базы (`Darth_Vader.md`, `Death_Star.md`), а не придуманы. Они задают модели формат и уровень детализации.

### Chain-of-Thought (CoT)

В System-промпте есть явное указание:
> «Сначала размышляй по шагам, потом дай финальный ответ.»

Формат ответа фиксирован: блок `Шаги:` с рассуждениями и блок `Ответ:` с итогом. Это снижает галлюцинации и делает ответ
проверяемым.

## Защита от галлюцинаций

System-промпт содержит правило: *«Отвечай ТОЛЬКО на основе контекста. Если ответа нет — напиши ровно "Я не знаю"»*.
Поэтому на вопросы вне базы знаний бот честно отвечает отказом (см. примеры ниже).

## Запуск

```bash
# Требуется переменная окружения AITUNNEL_API_KEY
export AITUNNEL_API_KEY=...

# Одиночный вопрос
python3 rag_bot.py "Что такое Void Core?"

# REPL
python3 rag_bot.py
#   Вопрос> Кто такой Zarn Velkor?
#   /sources — показать источники последнего ответа
#   /exit    — выход

# Перегенерировать демо-диалоги
python3 demo_dialogues.py
```

## Параметры

| Top-K            | 3                  |
| LLM              | gpt-4o-mini        |
| Temperature      | 0.2                |
| Max tokens       | 700                |

## Результаты

### 5 успешных диалогов

Все ответы сопровождаются цепочкой рассуждений (`Шаги:`) и корректным источником:

| # | Вопрос                                   | Источник                                                         |

| 2 | Что такое Void Core и чем он опасен?     | [`Death_Star.md`](../Task2/knowledge_base/Death_Star.md)         |

| 5 | На какой планете вырос Dorin Venn?       | [`Luke_Skywalker.md`](../Task2/knowledge_base/Luke_Skywalker.md) |

### 2 случая «Я не знаю»

| # | Вопрос                          | Ответ        |
|---|---------------------------------|--------------|
| 1 | Как приготовить борщ?           | `Я не знаю.` |
| 2 | Кто выиграл ЧМ по футболу 2022? | `Я не знаю.` |

Найденные фрагменты в этих случаях нерелевантны, и бот корректно отказывается отвечать, не выдумывая факты.
